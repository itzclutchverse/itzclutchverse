<h3 align="center">Learning something new every day.</h3>

I spend most of my days in Jupyter notebooks, usually halfway through cleaning a messy dataset before realising the schema makes no sense. Lately I've been moving from pure analytics toward building proper ETL pipelines with DuckDB and Python, trying to figure out where analysis ends and engineering begins. Pandas got me here, but I'm increasingly curious about what happens when you treat data like infrastructure instead of a notebook.
